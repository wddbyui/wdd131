Final Project - Planning

    Project Requirements

    1. The web project must be hosted on the web.
    2. The project must satisfy the following requirements:
      1. Content appropriate for your audience, so that they can understand the meaning and directions for this app.
      2. At least one image that relates to the content of the page.
      3. Be laid out and styled according to your plan wireframe(s).
      4. Be responsive and designed with mobile first in mind.
      5. Be visually appealing and easily readable.
      6. Be valid HTML and CSS
      7. Score on Lighthouse at least 90 on Performance and a 96 on Accessibility.
      8. You can also try: https://pagespeed.web.dev/ for performance as well. If you use this site you need to score 95 or above.
    4. The site should have dynamic elements provided by Javascript, your code should show include the following:
      1. It should show some level of organization: at a minimum it should have more than one function.
      2. It should include DOM interaction: select an element, modify it, and listen for and react to events
      3. It should show examples of conditional branching
      4. Each of the following should be used: Objects, Arrays and at least one array method usage (forEach, map, reduce, filter, etc)

Activity Instructions

In the previous weeks you should have come up with an idea for your personal web application. Before we build our personal (final) project we need to do some planning. You have seen site plans used to build other projects. They contain many of the details we needed to know in order to build sites. We should prepare a similar document for our personal application now.

  1. File Management:

    2. Let's start by adding a folder within the 'wdd131' folder. You can do this in file management or on Visual Studio Code.

    Give this folder a name and remember this will be a part of the URL (web address), so keep it short, simple, and professional. The folder name should be all lowercase with no spaces. The name should also have something to do with the topic of your project. This folder will be at the root level of your directory and will contain the new project.

    Add a file to your new folder called app-plan.html.

  2. Instructions:

    3. You have two options for your app plan. One option is to create your own app plan from scratch. You are not required to use a template. For either option you need to provide the following for your app-plan: purpose, audience, dynamic elements used, pseudocode (planned out logic of the code), and wireframes.

    The other option is to use an existing template by going to Web App Plan Template, right-click on the page, and view the source code. (On Chrome it's the pop-up menu option called 'View Page Source'.)

    To use the template, copy all the HTML code. You can use Cmd+A or Ctrl+A to select it all quickly, then copy it.

    Paste the code into your site-plan.html page in VSCode and save the file.

    Create a new 'styles' folder. And create a site-plan.css file inside that folder.

    Go to: Site Plan CSS and copy all the code.

    Paste the code into the site-plan.css file in VSCode and save it. Then complete each section.

    Purpose and Audience

    In 2–3 sentences, write a purpose statement for your site and write about your intended audience.

    Description of the Dynamic Elements

    Describe how you will use Javascript to add dynamic elements to your site.

    Pseudocode - Computational Thinking

    Write the out the logically steps of how you plan to code your application.

    Wireframe

    Create a wireframe for your project. Add your wireframe as an image or link to the site plan. If there are multiple pages, include one wireframe for each page.

    Submit

    As soon as you have this plan completed submit it! The sooner you get it approved the sooner you can get started building your project. Don't wait until the last minute on this one!

    Remember, we don't have an index.html or home page inside our personal site project folder yet. So you have to type in the app-plan.html at the end of the URL web address and select Enter to get it to open.

    Something like this:

    your-account.github.io/wdd131/personal-folder/app-plan.html

    Your web app plan should then come up. Use that URL to submit.

    Submit the GitHub link to your site-plan.html page to I-Learn.
