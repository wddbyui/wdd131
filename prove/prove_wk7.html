Prove - Event Ticket Form

Form validation

File Management:

Your project should be in a folder called 'eventform'. Make sure you have an index.html page and separate CSS and JS files.

Instructions:

Create a form that allows student to sign up for an event. They need to choose a date that is later than the current date.

This demonstrates how it will look.

Using the 'Type' drop down select element, the user also indicates if they are a student or a guest.

Once they choose one or the other, a hidden div containing a label and the input area will show up on the form.

If they are a student the input label will indicate 'Student I#' and they need to enter a 9 digit student I number.

If they are a guest the label will indicate 'Access Code' and they need to enter the event code 'EVENT131'

If there are any errors the user needs to know about when the form is submitted, place them below the form.

Give the user some ticket information after a successful submit.

Include a favicon that will show up on the browser tab.

Submit your project

Commit your changes, then push them to GitHub. Wait a few minutes then check to make sure they show on Github pages.

After verifying that your page updated, submit the URL to your page in Ilearn. The URL will look something like this:

https://githubusername.github.io/wdd131/eventform

Make sure to replace "githubusername" with your actual github username.
